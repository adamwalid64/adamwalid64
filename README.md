**FightMetricsAI** — UFC fight outcome predictor
Ensemble model (MLP, XGBoost, CatBoost, logistic regression) hitting 80%+ accuracy, plus a GPT-4 RAG layer over 60,000+ fight records for 4,000+ fighters. Python, SQL, React/Flask, Playwright.

Replaced a manual ETL process with an automated pipeline pulling from Spotify, Instagram, and ClickUp APIs, tracking growth across 1,000+ artists. Built a chatbot into ClickUp for live analytics. Python, SQL, Supabase/PostgreSQL.
